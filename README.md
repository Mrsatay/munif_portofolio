# Munif Novianto Portfolio

Personal portfolio website for **Munif Novianto**, a Threads Growth & Organic Content Strategist.

The site presents Munif's experience, audience insights, case studies, services, pricing, contact information, and an interactive AI assistant for potential clients.

## Highlights

- Responsive portfolio layout for desktop and mobile
- Threads growth strategy and organic content services
- Audience and performance statistics
- Viral content case studies
- PayPal payment links for service packages
- Contact section with email, phone, and Threads profile
- Interactive Gemini-powered AI assistant
- Scroll progress indicator and subtle reveal animations
- Social sharing and SEO metadata

## Run Locally

Because this is a static HTML project, no build process is required.

1. Download or clone the repository.
2. Open `portfolio.html` in a browser.

For a local development server, you can use any static server. For example:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000/portfolio.html](http://localhost:8000/portfolio.html).

## Deploy With GitHub Pages

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the main branch and the `/root` folder.
6. Save the settings and wait for GitHub Pages to publish the site.

The published page will usually be available at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

## Customization

The main content and styling are contained in `portfolio.html`. The profile image can be replaced by updating `munif.jpeg` or changing the image path in the HTML.

External resources currently loaded by the page include:

- Tailwind CSS CDN
- Google Fonts
- Marked.js CDN for chat markdown rendering
- Google Gemini API for the AI assistant
